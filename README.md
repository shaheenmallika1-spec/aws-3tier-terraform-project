
# AWS 3-Tier Infrastructure with Terraform

## Objective
Build a highly available AWS application using Terraform.

## AWS Region
Sydney (ap-southeast-2)

## Architecture
- Custom VPC across two Availability Zones
- Public subnets for the Application Load Balancer
- Private subnets for EC2 application instances
- Private subnets for Amazon RDS
- Auto Scaling Group
- Security groups and IAM roles
- CloudWatch monitoring
- S3 remote Terraform state
